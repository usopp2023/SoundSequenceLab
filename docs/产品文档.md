## 1. 产品概述

**一句话定位**：把说不出口的情绪，谱成一段只属于你的民乐。

**品牌**：声序实验室（SOUND SEQUENCE LAB）—— 把不同空间里被触动的瞬间，转译成声音。
**首个活动**：阿那亚 · 情绪民乐（活动期 2026.06.16 – 06.29）。

**产品形态（双渠道，同一套后端）**
- **线上**：微信小程序，用户在自己手机上体验，生成的内容天然归属本人。
- **线下**：阿那亚现场的公用体验机（平板，H5 网页），供到访者即时体验；生成结果通过「认领码 / 二维码」绑定到用户自己的小程序账号。

**核心价值**
- 把抽象情绪转化为可听、可留存、可分享的「情绪民乐」+「人格标签」+「情绪曲线」。
- 低门槛表达：语音优先、三个问题、约一分钟。
- 社交裂变：分享卡片、与朋友比相似度、广场围观他人作品。

## 2. 目标用户与使用场景

| 用户 | 场景 | 入口 |
|---|---|---|
| 阿那亚到访者 | 现场体验机即时玩一把 | 现场平板（kiosk） |
| 到访者回家 | 把现场作品认领到自己账号、领权益 | 自己手机小程序输码/扫码 |
| 线上用户 | 自己手机直接玩、分享 | 小程序 |
| 被分享者 | 朋友分享卡片点开 | 玩过→看相似度；没玩过→被引导体验 |

## 3. 设计语言

- **配色**：燕麦白底（`#ffffff`/`#f0eeea`）+ 中性灰阶（`#1c1b1a`/`#6b6864`/`#9a9792`）+ 赤陶点缀（`#b5613f`）。
- **字体**：标题衬线（Songti SC），正文无衬线（PingFang SC）。
- **质感**：圆角卡片、轻投影；呼吸/波纹/录音脉冲/波形等克制动效。
- **广场**：扁平插画海滩，低饱和雾青 + 燕麦沙，**随真实时间变色**（清晨/白天/黄昏/深夜四套），作品以漂浮「光球」呈现。
- 隐私优先的克制表达：不炫技、不喧哗。

### 双层导航（产品关键设计）

- **品牌层**：实验室（首页） / 我的

## 5. 核心用户旅程

### 线上主流程
```
活动主页 → 答题(语音/打字, 3题) → 生成(等待) → 结果(人格+四维+曲子, 自动存档)
                                                  ├→ 生成分享卡片 → 转发
                                                  └→ 完成，进「我的活动」
```

### 线下主流程
```
现场体验机：答题 → 生成 → 结果 + 认领码/二维码
用户自己手机小程序：我的活动 → 兑换码 → 扫码/输码 → 认领作品+权益 → 进自己档案
```

### 分享裂变
```
我分享卡片 → 朋友点开
  ├ 朋友玩过 → 看「你们有多像」相似度
  └ 朋友没玩过 → 「一位朋友想知道你们有多像」引导页 → 去体验
```

## 6. 功能模块详解

### 6.1 实验室（品牌首页）
- 品牌区：声序实验室 + slogan。
- 正在进行：阿那亚·情绪民乐卡片（含活动日期 2026.06.16–06.29）→ 进入活动。
- 即将到来：占位预告。

### 6.2 我的（个人中心，品牌层）
- 微信身份（头像 + 昵称；点击进「设置头像昵称」）。
- 我参与过的活动：阿那亚·情绪民乐 → 进活动。
- 我的奖励（跨活动总览）：专属皮肤 + 限定勋章，未解锁为锁定预览。
- 设置：消息通知、关于。

### 6.3 活动主页
- 活动介绍 + 「怎么玩」三步。
- 「开始」→ 答题。
- 「线下体验过？输入兑换码 →」→ 兑换码/认领页。
- 隐私承诺：你的回答只用于生成你的音乐，不会公开给任何人。

### 6.4 答题（语音优先 / 打字兜底）
- 三个问题，进度条。
- **语音**：点麦克风录音（脉冲动画 + 波形 + 计时），结束后得到可编辑的识别文字。
- **打字**：随时切换。
- 体验细节：当前题没有任何输入时「下一题」置灰；返回上一题能看到之前填的内容。
- （现场体验机 H5 的答题流程与此完全一致。）

### 6.5 生成
- 分步文案：正在听你说的话 → 读出你藏起来的情绪 → 正在谱一段曲子。
- **失败态**：网络/超时失败时显示「这次没能谱成曲子」+ 重新生成 / 稍后再说。
- 退出确认：避免误触丢失。

### 6.6 结果
- 人格名（如「黄昏独行者」）。
- **情绪四维**（圆点在轴上的位置）：独处↔共处、涌动↔平静、直说↔含蓄、回望过去↔望向远方。
- 「关于你」一段解读。
- 曲子播放器（波形动效）。
- 自动存入「我的活动 · 情绪档案」。
- 出口：完成查看我的 / 生成分享卡片。

### 6.7 分享卡片
- 一张带人格名、英文名、金句、二维码位的卡片。
- 转发到群/好友：携带人格参数，朋友点开按「是否玩过」分流。

### 6.8 相似度
- 大号百分比 + 你 vs Ta 的人格 + 一段解读。
- 从「广场作品详情」或「分享卡片」进入。

### 6.9 广场
- 全屏海滩，随时段变色。
- 漂浮「光球」展示作品（随机布局、不重叠、缓慢浮动），点开看详情。
- 「换一批」刷新。

### 6.10 广场作品详情
- 听 Ta 的曲子、看关于 Ta。
- ♥ 喜欢（= 收藏到「我的活动 · 我收藏的」）。
- 「和 Ta 比相似度」。

### 6.11 我的活动
- 活动内身份（微信昵称头像，点击可设置）。
- 我的情绪档案：历次结果卡片（可再测，旧的保留）。
- 我收藏的：广场点 ♥ 的作品（可 ✕ 取消）。
- 我的权益（见第 7 节）。
- 我的奖励（见第 7 节）。
- 输入兑换码 · 领取完整权益。

### 6.12 消息通知
- 生成完成、社交匹配、活动开启等（当前为示例数据，真实事件触发待接）。

### 6.13 关于
- 品牌介绍 + 做过的活动。

### 6.14 登录与账号
- **静默登录**：打开即用，后端按用户隔离档案/收藏/解锁，无弹窗、不挡路。
- **按需头像昵称**：在「我的 / 我的活动」点身份区，用微信最新「头像昵称填写能力」（选头像 + 填昵称）设置；不设置则显示「微信用户 + 默认头像」。
- 说明：微信旧的 `getUserProfile` 一键授权头像昵称已废弃，故采用用户自填方式。

## 7. 权益与奖励体系

### 权益（两档）
- **基础档**：完成线上体验即得（示例：阿那亚冰箱贴 8 折、喜茶 9 折券）。
- **完整档**：通过兑换码/现场认领解锁后，覆盖基础档（示例：冰箱贴 6 折、喜茶 8 折、瑞幸 6 折、专属皮肤 + 勋章）。

### 奖励（解锁完整权益后点亮）
- **专属分享卡片皮肤**：分享到群聊时的限定卡面。
- **阿那亚限定勋章**：完整体验过的专属标记。
- 未解锁时以「锁定预览」展示，营造收集感。

> 解锁入口：兑换码页。演示用兑换码 `anysxzn2026`（仅解锁权益）；现场认领码（绑定作品 + 解锁权益）。

## 8. 现场体验机（kiosk）

- **形态**：阿那亚现场一台公用平板，浏览器全屏跑 `kiosk/index.html`（H5），接同一套后端。
- **流程**：欢迎 → 答题（与小程序一致：语音优先 + 打字兜底、上一题、答案恢复）→ 生成（含失败重试）→ 结果（人格/四维/曲子）+ **认领码 + 二维码** → 「完成，下一位」重置给下一个人。
- **为什么是网页**：公用设备一个接一个换人，不适合绑定个人微信登录；H5 复用最初的网页原型，天生适合现场机。
- **录音限制**：浏览器录音需 https 或 localhost；现场若用普通 http，录音自动降级为打字。

## 9. 线下认领闭环（关键机制）

**要解决的问题**：现场设备是「我们的」，生成那一刻没有用户本人的微信身份，作品怎么变成他自己的？

**方案**：把「生成」和「认领」分开——
1. 现场生成结果 → 后端先挂成「待认领」+ 生成一个**一次性认领码**（8 位）+ 对应二维码。
2. 现场屏幕显示二维码 + 文字码。
3. 用户用**自己手机的小程序**：我的活动 → 兑换码 →「扫码认领」（`wx.scanCode` 扫二维码）或手输码。
4. 后端把该结果**绑定到用户本人 openid**（进他的档案）+ 解锁权益；认领码**一次性**，已领即失效。

> 与兑换码统一为一个入口：认领码=认领作品+解锁权益；演示/权益码=仅解锁权益。
> 升级项：拿到正式 AppID 后，二维码可换成微信「小程序码」，支持用微信原生**冷扫码直接打开小程序并自动认领**（连"先打开小程序再扫"都省了）。

## 10. 情绪分析与音乐生成

**分工铁律**：分析归多模态大模型，生成归 Suno。

- **录音 → 文字/情绪**：用户语音上传后端，由能"听"音频的多模态大模型分析情绪、提炼人格标签与四维。
- **音乐生成**：把分析结果组织成 prompt 喂 Suno，按情绪生成多个音乐片段，再合成一首完整曲子。
- **人格 + 四维**：每次生成得到一个人格名（如黄昏独行者/深海回声者…）与四维坐标，作为相似度匹配与展示依据。
- **降级**：生成失败/超时回退兜底，不让用户卡死。

> 当前阶段：分析与音乐生成为**占位实现**（接口已按真实形态设计，可无痛替换）；端到端流程已真实跑通。详见 `docs/未完成事项.md`。

## 11. 数据与隐私

- **隐私承诺**：答题前明示「你的回答只用于生成你的音乐，不会公开给任何人」。
- **广场只展示结果**（人格/曲子），**不展示用户的回答**。
- 密钥与第三方调用只在后端，前端不接触任何 key。

## 12. 技术架构概览

```
微信小程序  ┐
            ├─→  自有后端（FastAPI，统一 /api）  ─→  多模态大模型（分析） + Suno（生成）
现场 H5 体验机 ┘                                   └─→  SQLite（档案/收藏/认领码）
```
- 小程序与现场体验机**共用同一套后端接口**（答题、上传、生成、结果、广场、相似度、认领等）。
- 开发期前端连本地后端；上线需后端备案 https 域名。
